function merge(intervals: number[][]) { // sort by start const sorted = [...intervals].sort((a, b) => a[0] - b[0]); const out: number[][] = []; for (const [start, end] of sorted) { const last = out[out.length - 1]; if (last && start <= last[1]) last[1] = Math.max(last[1], end); else out.push([start, end]); } return out; }

The rules

Shape
  • Type plus duration sets the structureNever a minutes-per-question slider. Concepts are N questions with follow-ups; design is four phases; DSA is 1–3 problems.
  • Five typesJavaScript, React, TypeScript, Behavioural, Mixed. Machine coding is out — it needs a mini-IDE, and a build you did elsewhere is a ledger item with a repo link and a deployed URL.
  • DSA, System design and voice are absent, not disabledNone of the three is built. A disabled control says "this exists and is one click away", which would be a lie about a feature that does not exist — so there is no control at all. The rule is about what a control's presence promises, and it stands on its own now that nothing on this screen is disabled.
  • Every question comes from your library, weighted toward weakThe pool line under each type is read from your data and says honestly when a round would be thin.
  • Follow-ups arrive when an answer leaves an openingNot on a fixed count. They are the point of the round.
  • Three groups, three defaults, three checksRound, length and interviewer each default to their first option and each shows a check on arrival, so the summary is true before you touch it and the ticks say these are yours to change. Enter the room is never disabled: a round cannot be unconfigured, so there is nothing for a gate to prevent.
  • End the round always worksIt is the only escape from a stuck exchange. It never waits on a model call, and it is never disabled while one is in flight — an interviewer that cannot be walked out on is a trap, not a simulation.
The six additions
  • Interviewer level is a prompt, not a multiplierFriendly senior, staff, skeptical principal. It changes how hard follow-ups push. A harder interviewer does not lower your score — the dimensions measure what you said, not who asked.
  • Asking a clarifying question counts for youReal rounds open with questions. Ask a question is its own action so a question is never scored as a wrong answer, and Enquiry is a scored dimension.
  • Three hints, each visible on the scorecardA hint is a real interview move; asking for the answer is not. The cost is transparency, never a hidden penalty — the row shows "1 hint" beside the score it earned.
  • A follow-up can become a quiz, during the roundPress, look at the drafted distractors, press again. Two presses and no navigation — the room is forbidden from telling you that you got it wrong, and a thing you have not looked at is not a thing you chose. Saved to your library, linked to the topic the follow-up came from. The only thing in a round that feeds the library rather than the scorecard.
  • Rewind re-asks one question and never changes the scoreImmediately, while it is fresh. It produces its own small result. A score you can retry until it improves is not a score.
  • Voice is Chrome-only and always has a typed fallbackRecognition runs in the browser; no audio is stored or sent, only text. You edit the transcript before sending, so a mis-hearing costs a correction rather than a wrong answer.
Scoring
  • A score for the round, never for what you knowConfidence stays yours; the scorecard offers and you confirm.
  • Four dimensions, because one number hides the findingRecall 86 and Depth 58 is the whole story — you know what things are and go thin when asked for a consequence. A single score averages that away.
  • Comparison is to your own past rounds onlyNo benchmark, no percentile, no other people.
  • It says what it did not askWithout that line, 74 reads as a verdict on your JavaScript rather than on eight questions.
What persists
  • The scorecard, your DSA code, and any quiz you savedThree things, all yours or derived from what you did.
  • The conversation is discardedMostly model prose, never reread, and storing it builds the second library this product has refused for seven arcs.
Not built
  • Nothing is executedNo code runner, no test harness. The model reads your code as text, the way an interviewer reads a whiteboard.
  • No benchmarks, percentiles, leaderboards or streaksSeven arcs of exclusions, inherited. Only the no-AI line was ever retired.
  • No round is ever resumedA round is 45 minutes of continuous attention or it is not a round. Leaving loses it, and the setup screen says so.
