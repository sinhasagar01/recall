React reconciliation

Reactrenderingperformance·Medium
Definition

React compares the previous and next element tree to work out what actually changed, then commits only those mutations to the DOM. Elements are compared by type and key; a changed type discards the subtree entirely rather than trying to patch it.

Mental model

Like an editor diffing two drafts. It doesn't retype the document — it finds the changed paragraphs and rewrites only those. And if you swap the chapter itself, the editor doesn't bother diffing at all; it starts that chapter over.
