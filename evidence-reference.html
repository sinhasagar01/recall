The rules

Every decision this reference encodes. Where this page and the screens disagree, the screens win.

What it is
  • Four markers, three recordableRecall is derived from the existing confidence and is never stored or edited here. Rebuild, Challenge and Production are each absent, or present with a date, a required note, and an optional URL.
  • It encodes one sentence“Weak until you can explain it, implement a variant, and use it in a design decision.” That sentence sits above the row, in the product, so the row is never four checkboxes without a reason.
  • An ADR is a URLThe link field is the entire integration with any document, PR or diagram. The product stores no documents.
What it does not do
  • It never touches practiceEvidence is not an input to practice selection, ordering, the weak page, or any count. The queue stays one rule I can state in a sentence.
  • It never appears on a quizA quiz is a retrieval device, not a concept. The shape constraint rejects evidence on a quiz row, and the section is absent rather than empty.
  • It has no completion stateNo badge, no celebration, no “complete”. Four ticks is the whole signal.
  • It is not scheduledNo due dates, no next-review, no 1–3–7–21. That cadence is being run manually, outside the app, by decision.
  • It is not counted anywhere elseNo dashboard, no phase progress, no capability map. Those are separate decisions and none of them is being made here.

An earlier draft of this reference drew cards with no Model ✓ at all; that was an oversight, not a decision, and the fallback is the rule.
  • Green already exists — corrected--ok #1B6B4F and --ok-soft #E6F2EC are already in the palette; the quiz phase added them for a correct answer. An earlier draft of this page claimed they were new to DESIGN.md, which was false. Evidence reuses them rather than re-adding them, and it earns them for the same reason a quiz answer does: both are genuinely binary — done or not — so green is neither the indigo of selection nor the crimson of alarm. Green is still never used for confidence, which is a judgement rather than a fact.
