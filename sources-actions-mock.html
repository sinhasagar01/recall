One chapter means one button

Your course has a single chapter, so "practise this chapter" and "practise this course" resolve to the same 21 entries. Two buttons producing an identical session is not a layout problem — it is a missing rule. An action appears only when its session differs from the wider one’s: if two scopes resolve to the same set of entries, only the widest is shown. A single-chapter course is one case of that. So is a chapter with a single lesson. So is a chapter whose sibling chapters have nothing distilled yet — its entries are the course’s entries, and the course button is the one that stays.

Both are buttons now, not links. They start a session — an action, not navigation — and the shipped Button is what every other action in this app uses. The count moves out of the label and beside it, so the button says what it does and the meta says how much.

Corrected: the course count belongs on the right, and it counts MINED

This screen first drew the course sub-line ending “· 0 of 1 finished”, which contradicted sources-hierarchy-mock.html twice over. That file puts the count in its own element on the far right — it is the course's summary judgement, not the tail of a list of four numbers — and the count it puts there is mined, not finished.

Mined is “this lesson produced something”; finished is “every entry is okay or better”. The older mock specifies the course head, so it wins: the sub-line carries the plain counts and the right-hand element carries N of M mined. The lesson meter is where finished is shown, one row down.

Each action sits at the end of what it covers

The chapter button lives in the chapter band, which is the only row that belongs to the chapter and nothing else. The course button is in the card footer, after every chapter. Nothing sits above the content it acts on — the old layout put "practise this course" above the chapter, so it read as belonging to the chapter beneath it.

A chapter with nothing distilled shows no button rather than a disabled one — the shipped rule from the quiz options and the empty intention box. A session of zero entries is not a session.

What replaces the five dots

The old dots counted the five-item extraction checklist, which arc 6 deleted. What shipped in its place is one grey dot meaning "finished", and it is too quiet to read — you had to ask what it was.

Same five marks you were used to, now measuring something real: how much of this lesson you can actually recall. Dashed and empty means nothing distilled; all five filled means finished.

A bar
rejected

Reads as a percentage, and this app has refused percentages since the first spec. Five discrete marks say "some of it" without implying a precision the number does not have.

It uses the palette's existing meaning

--ok marks what the app derives from facts, and this is derived — entries at okay or better, over entries from this lesson. Nothing here is a self-report, so the green is the same claim it makes everywhere else. Empty squares are the confidence meter's own idiom, one level up.

Five squares, not three, because five was the shape you were reading before and the granularity is free. A lesson with 21 entries and 3 at okay or better fills one square; with 11 it fills two. The tooltip and aria-label carry the exact numbers, so the marks are a glance and the text is the truth.

The rules

Practise actions
  • Buttons, not linksThey start a session. Every other action in this app is a Button; these were the exception and should not have been.
  • Each sits at the end of what it coversThe chapter's in the chapter band, the course's in the card footer. Nothing above the content it acts on.
  • Never two actions producing the same sessionA course with one chapter shows only the course button. A chapter with one lesson shows only the chapter button. The rule is general: if two scopes resolve to the same set, show the widest one.
  • No button when there is nothing to practiseAbsent, not disabled — the shipped rule from the quiz options and the empty intention slot.
  • The count sits beside the button, not inside the labelThe button says what it does; the meta says how much.
The lesson meter
  • Five squares, filled by entries at okay or betterReplaces the single dot. Derived from confidence, so --ok means what it means everywhere else.
  • Dashed and empty means nothing distilledThe confidence meter's own idiom for "no data yet", one level up.
  • All five filled means finishedEvery entry at okay or better — the same rule the word already carries in the course header.
  • The exact numbers live in the tooltip and the aria-labelThe marks are a glance; the text is the truth. Colour is never the only signal.
  • Not a bar and not a percentageA bar reads as a percentage, and this app has refused those since the first spec. Five discrete marks say "some of it" without implying precision that is not there.
